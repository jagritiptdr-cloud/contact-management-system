Mini Project · Data Structures

Contact Management System

A fully static web application (HTML · CSS · JavaScript) where every core operation is backed by a data structure written from scratch — no frameworks, no database, no server.

🎯 Objective

To design an efficient contact manager that shows how choosing the right data structure makes each operation fast — instant search while typing, always-sorted lists, one-click undo and smart reminders.

❓ Problem statement

A simple array of contacts needs O(n) time to search, O(n log n) to sort every time, and cannot undo mistakes. As the list grows, the app becomes slow. We replace the array with specialised structures.

🧱 Data structures used

Data structureUsed forWhy this one?Complexity
HashMap (separate chaining, djb2 hash)Store contacts by ID; detect duplicate phone numbersDirect lookup without scanning the listO(1) avg

AVL Tree (self-balancing BST)Alphabetical A→Z / Z→A listingList stays sorted after every insert/delete; rotations keep height ≈ log nO(log n)

Circular Queue (FIFO, fixed size)Recently viewed contactsOldest entry drops out automatically, no shiftingO(1)
Min-Heap (priority queue)Upcoming birthday remindersAlways gives the nearest birthday firstO(log n)
Merge SortSort by date addedStable and guaranteed n log nO(n log n)

✨ Features

  • Add, edit, delete, view contacts
  • Instant prefix search (Trie)
  • Sort A–Z, Z–A, newest, oldest
  • Favourites & groups
  • Unlimited-style undo (Ctrl + Z)
  • Recently viewed & birthday reminders
  • Import / export JSON
  • Dark mode & fully responsive

🛠 Tech stack

  • HTML5 — structure
  • CSS3 — grid, flexbox, variables, animations
  • Vanilla JavaScript (ES6 classes)
  • SVG — tree visualisations
  • LocalStorage — saves data in browser
  • No backend, no libraries
